# 初始化

## 步骤

1. 在空数据库上手工执行 `src/main/resources/db/schema.sql`：建表，并写入内置菜单（系统管理、项目设置、数据中心、服务器管理）。系统设置表为空，系统名称默认为 `admin-front`，可在「系统管理 → 系统设置」修改。
2. 启动服务。`SystemInitializationService` 在启动时：
   - 确保内置平台角色「超级管理员」（`SUPER_ADMIN`）存在，并关联全部平台菜单；
   - 系统里一个账号都没有时，创建初始超级管理员账号。
3. 用初始管理员登录。此时还没有项目，界面会强制弹出「新建项目」；创建后自动生成该项目的「项目管理员」角色。
4. 之后在「用户管理」创建其他账号，在「角色模板」维护模板，在各项目的「成员管理」把账号拉进项目。

## 初始管理员

| 配置（`conf/application.properties`） | 默认值 | 说明 |
| --- | --- | --- |
| `admin.init.account` | `admin` | 登录名 |
| `admin.init.password` | 空 | 为空时随机生成 16 位密码，并以 WARN 级别打印到启动日志 |

只在 `account` 表为空时创建一次，之后修改配置不会影响已有账号。登录后应在「用户管理」里重置密码。
