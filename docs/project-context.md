# 项目上下文

当前项目保存在登录会话中（Redis `login:project:<token>`），每个会话独立，多标签页、多设备互不覆盖。`account.last_project_id` 只作为下次登录默认进入的项目。

- 客户端先调用 `/api/project/list`：依次取会话项目、上次使用的项目、列表第一个，写回会话。
- 切换时调用 `/api/project/switch`，成功后重新获取项目列表和菜单。
- 项目接口（成员、项目角色以及后续的数据查询、日志、模板、监控、运维接口）都携带 `projectId`，服务器通过 `PermissionService.requireProjectMenu` 校验它等于会话当前项目，不一致返回 `100027`；客户端收到后以服务器为准重新同步项目和菜单，不自动重试写入。
- 后续项目业务接口还要检查模板、进程等资源属于该项目。资源归属必须来自服务端保存的配置，不能只信任客户端传来的地址或主机；执行时使用本次校验通过的项目 ID，不重新读取当前项目。
