# 管理后台权限规则

## 账号与角色

账号由有 `manage_user` 权限的调用者创建。旧 `account.admin=true` 只用于一次性迁移到“超级管理员”角色，迁移后不参与业务判断。

初始只创建内置全局角色“超级管理员”。其他角色由角色接口创建，项目角色通过 `project_user.role_id` 分配给账号。

## 权限来源

角色通过 `role_menu` 获得菜单权限。账号级角色与当前项目角色共同决定当前菜单。客户端调用 `/api/access/menu`，服务器业务接口再次按同一关系校验。

超级管理员可以访问全部项目，并拥有初始化菜单权限。其他角色只能访问自己挂载的项目和被分配的菜单。

## 菜单

菜单类型只有目录和菜单。前端页面必须先注册路由，再由菜单管理写入服务器。新菜单自动关联超级管理员。内置菜单不能修改或删除。

## 项目

超级管理员的项目列表包含全部项目；普通账号的项目列表来自 `project_user`。切换项目后客户端重新请求 `/api/access/menu`。
