# 关闭 / 重新启用项目

需要平台菜单 `manage_project`。

`POST /api/project/close`，请求体 `{"projectId":1}`：项目状态改为 2（已关闭），成员和项目角色保留。已关闭项目不出现在切换列表中，不能切换进入；清除指向该项目的 `last_project_id`。目标项目已关闭时返回 `100025`。

`POST /api/project/reopen`，请求体 `{"projectId":1}`：项目状态改回 1（正常），原有成员和角色恢复可用。

成功 `data` 均为 `null`。

错误：`100001` 参数不合法，`100003` 未登录，`100016` 无权访问，`100025` 项目不存在或已关闭。
