# 当前账号菜单

`POST /api/access/menu`

客户端登录后、切换项目后调用，返回当前会话可用的菜单。

请求体：`{"projectId": 1}`，值为项目列表返回的 `currentProjectId`。

## 处理顺序

1. 校验令牌和账号状态（禁用账号视为未登录）。
2. 请求的 `projectId` 必须与会话当前项目一致，不一致返回 `100027`。会话没有当前项目时只允许 `{"projectId": null}`。
3. 平台菜单：账号级平台角色（`account_role`，`role_type=1`，启用）关联的平台菜单（`scope=1`）。
4. 项目菜单：会话当前项目未关闭且账号可访问时加入。超级管理员为全部启用的项目菜单；其他账号为其在该项目中的项目角色关联的项目菜单（`scope=2`）。
5. 只返回 `status=1` 的菜单，按父级、`sort`、`id` 排序。`hidden=true` 的菜单仍返回，只是不在侧栏展示。

## 成功

每项字段：`id`、`parentId`（顶级为 0）、`menuType`、`scope`、`name`、`icon`、`routeName`、`routePath`、`status`、`hidden`、`builtIn`、`sort`。

## 失败

`100001` 参数不合法，`100003` 未登录，`100027` 请求项目与会话当前项目不一致。

服务器业务接口会按同一套规则再次校验，客户端隐藏菜单不能绕过权限。
