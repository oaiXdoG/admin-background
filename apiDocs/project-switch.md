# 切换项目

不存在或已关闭的项目不能切换，包括超级管理员；返回 `100005`。

`POST /api/project/switch`

请求体：`{"projectId":1}`。

处理顺序：校验令牌和项目编号；超级管理员校验项目存在即可切换；其他账号必须存在对应的 `project_user`；通过后更新 `account.last_project_id`。

前端以成功响应的 `currentProjectId` 确认切换，依次刷新项目列表和该项目的菜单。刷新或校验失败时暂停页面操作，提示用户重新切换，不恢复成可操作的旧项目页面。

项目相关请求必须携带 `projectId`，服务端校验其与账号当前项目一致。即使登录账号相同、来自不同标签页，也不允许用旧项目 ID 继续操作。切换接口本身的 `projectId` 是目标项目，无需与切换前的当前项目相同。

错误：`100001` 参数不合法，`100003` 未登录，`100005` 不能切换到该项目。
