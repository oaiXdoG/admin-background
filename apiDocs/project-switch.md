# 切换项目

`POST /api/project/switch`，请求体 `{"projectId":1}`。只需登录。

目标项目必须存在且未关闭；超级管理员可以切换到任何项目，其他账号必须是该项目成员。通过后写入**会话**当前项目，并更新 `last_project_id` 作为下次登录的默认项目。同一账号的其他会话不受影响。

成功 `data`：`{"currentProjectId":1}`。

项目接口必须携带 `projectId`，服务器校验它与会话当前项目一致，不一致返回 `100027`。

错误：`100001` 参数不合法，`100003` 未登录，`100005` 不能切换到该项目。
