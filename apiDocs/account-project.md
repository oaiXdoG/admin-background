# 账号项目关联

调用者必须拥有 `manage_user` 菜单权限。项目关联对应 `project_user` 表，每个账号在每个项目中只有一个项目角色。

## 查询

`POST /api/account/project/list`

```json
{"accountId":2}
```

成功 `data` 按项目 ID 排序，只返回未关闭项目的关联；没有关联时返回空数组：

```json
[{"projectId":1,"roleId":2}]
```

错误：`100001` 参数不合法，`100003` 未登录，`100016` 无权访问，`100028` 账号不存在。

## 保存

`POST /api/account/project/update`

```json
{"accountId":2,"memberships":[{"projectId":1,"roleId":2},{"projectId":3,"roleId":4}]}
```

提交未关闭项目的完整关联列表，服务器删除该账号在未关闭项目上的原有关联后写入新列表；已关闭项目的关联保留不变。`memberships` 为空数组表示移除全部未关闭项目的关联。

每条关联必须满足：项目存在且未关闭；同一项目只出现一次；角色存在、已启用且不是全局角色。全局角色（超级管理员）只能通过账号级角色分配，不能作为项目角色。任一条不满足时整体不保存。

成功 `data` 为 `null`。

错误：`100001` 参数不合法，`100003` 未登录，`100016` 无权访问，`100028` 账号不存在，`100029` 项目关联不合法。
