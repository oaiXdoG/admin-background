# 编辑账号

`POST /api/account/update`。需要平台菜单 `manage_user`。登录名不可修改。

```json
{"accountId":2,"username":"爱丽丝","remark":"运营部","password":"新密码"}
```

`username` 必填最长 64；`remark` 可选最长 128；`password` 可省略，省略时不修改，提交时不能为空白、最长 128。修改密码后该账号已登录的全部会话立即失效。

成功 `data` 为 `null`。

错误：`100001` 参数不合法，`100003` 未登录，`100016` 无权访问，`100028` 账号不存在。

# 启用 / 禁用账号

`POST /api/account/status`，请求体 `{"accountId":2,"status":2}`。需要 `manage_user`。

`status` 为 1 启用或 2 禁用。不能修改自己的状态。禁用后该账号不能登录，已登录的会话立即失效。

错误：`100001` 参数不合法，`100003` 未登录，`100016` 无权访问，`100028` 账号不存在，`100035` 不能对自己执行该操作。

# 分配平台角色

`POST /api/account/role/update`，请求体 `{"accountId":2,"roleIds":[1,5]}`。需要 `manage_user`。

提交完整的平台角色列表，整体替换 `account_role`。角色必须是平台角色（`role_type=1`）。分配或撤销「超级管理员」只能由超级管理员操作，并且不能撤销自己的超级管理员。

错误：`100001` 参数不合法，`100003` 未登录，`100016` 无权访问，`100018` 角色不存在，`100028` 账号不存在，`100035` 不能对自己执行该操作，`100036` 只有超级管理员可以分配超级管理员角色。
